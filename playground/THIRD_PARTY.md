# Playground third-party notices

The static playground redistributes an unmodified WebAssembly LLVM toolchain
and a WASI JavaScript shim. Copy this file and the entire `licenses/`
directory into the built site alongside those assets. Full upstream license
texts are retained there; `licenses/sources.json` records their source URLs
and SHA-256 hashes.

## WASI libc and compiler runtime

The YoWASP sysroot includes WASI libc, C/C++ headers and static libraries,
Clang builtins, and the LLVM C++ libraries. LLVM's license above covers its
compiler-rt, libc++, libc++abi and libunwind components; retain any additional
upstream notices when changing the packaged toolchain.

The release pins WASI libc commit
[`2fc32bc81b9f07f8d9525edea59bfbaf760c06d6`](https://github.com/WebAssembly/wasi-libc/tree/2fc32bc81b9f07f8d9525edea59bfbaf760c06d6).
Its upstream license inventory is retained in
[licenses/wasi-libc.txt](licenses/wasi-libc.txt), together with:

- [Apache 2.0 with LLVM exceptions](licenses/wasi-libc-APACHE-LLVM.txt),
  [Apache 2.0](licenses/wasi-libc-APACHE.txt), and
  [MIT](licenses/wasi-libc-MIT.txt).
- [cloudlibc BSD notice](licenses/wasi-cloudlibc-BSD.txt).
- [musl copyright and component notices](licenses/wasi-musl-COPYRIGHT.txt).
- [musl-fts BSD notice](licenses/wasi-musl-fts-BSD.txt).

The upstream inventory also identifies public-domain/CC0 dlmalloc and MIT
emmalloc. Their retained source notices are
[dlmalloc](licenses/wasi-dlmalloc-NOTICE.txt) and
[emmalloc](licenses/wasi-emmalloc-NOTICE.txt); complete sources are pinned here:

## JavaScript bundled by YoWASP

`gen/bundle.js` embeds YoWASP's runtime and nanotar, together with JavaScript
bindings generated by Bytecode Alliance JCO. The published package records
`@yowasp/runtime@11.0.67` and `@bytecodealliance/jco@1.15.1` as build inputs.

- YoWASP runtime 11.0.67: ISC,
  [retained license](licenses/YoWASP-runtime-ISC.txt),

- nanotar 0.2.0: MIT,
  [retained license](licenses/nanotar-MIT.txt),
  [source commit 7e35c5bd8d3f3b7565ba3aafa216eea636fc7b3c](https://github.com/unjs/nanotar/tree/7e35c5bd8d3f3b7565ba3aafa216eea636fc7b3c).

## Updating the assets

When upgrading a package, update the package hash, source snapshots, retained
notices and manifest together. Preserve additional license/copyright notices
from newly included source components rather than assuming one package-level
license covers the entire compiler toolchain.
