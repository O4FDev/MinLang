Decisions for you

  1. Astra cycle collector: not merged. Brought up to this v2 on port/astra-cycles-v2: JSON parsing +6-9%, Minyarcraft and the compiler within noise, self-referential chains +13-15%. Recommendation: merge once its cycle suites pass, if cyclic data is wanted soon.
  2. Default memory profile: macOS 26's free reads the clock (12% of JSON parsing). The lazy profile parsed the same history in 25% fewer instructions, and Atacama and Minyarcraft were unchanged under it. Recommendation: make lazy the default after one full suite run with it.
  3. http on macOS no longer caches: the URL cache made streaming quadratic and wrote responses to disk. Recommendation: keep it off.
  4. Atacama repo: now git, with branches v2-list then v2-stream. Recommendation: merge v2-stream; check Look Up and Writing Tools on the answer text.
  5. Old branches and 600 MB of research data: merged branches are listed in docs/v2-reconciliation.md. Recommendation: delete them and move the data out. Nothing was deleted.
