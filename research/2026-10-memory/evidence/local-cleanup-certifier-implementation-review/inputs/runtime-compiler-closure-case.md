# One generated function: a closed local component and an escaping caller root

**Result.** The archived Minyar `textures.snow` function discharges one concrete ownership-to-local-closure obligation: its two fresh scalar Lists have exactly one owner each, both are transferred into one temporary chunk, neither escapes, and the generated suffix detaches that chunk and retires its heap frame. At the boundary immediately before emitted `minyar_rc_step`, their remaining **component-attributed structural demand is exactly four units**: two owner visits, one chunk finalization, one frame finalization. This is a hand proof over saved actual LLVM and the pinned runtime, conditional on valid runtime/LLVM execution and eventual service. It is **not an observed four-unit measurement or a whole-process certificate**.

The same real caller supplies a decisive boundary failure for a stronger claim. `pixels` remains protected by `build`'s active local; `build` later retains and returns that alias, and `main` takes the returned producer owner. Function leave therefore does not establish process-wide root closure. The proof closes the small statically separated local component, while explicitly rejecting promotion to the original whole-universe theorem at this call boundary.

**Precise failure of global closure and the returned alias.** The actual `build` caller still owns `pixels` in active local slot zero while `snow` closes. The scalar byte writer neither consumes nor retains that Bytes token (Y:101–106). `snow`'s leave pops only its own frame (R:305–316); it cannot detach `build`'s root. `drawTile` also has an active heap frame (IR:1497), and `main` has its active owner frame (IR:6605). Their latent obligations and any unrelated queued debt are absent from Wlocal. The original Byte-free, uniformly tracked whole-universe theorem therefore has false premises here.

At `build` return, the exact alias `%value.29` is retained **before** leave (IR:4148–4152), then becomes a producer held by the caller, then is transferred by `main` to slot zero (IR:6648–6650). Between retain and caller registration, that escaping token may protect Bytes during leave's automatic poll; it is outside a callee-only census. Afterwards it is a live caller root. These instructions are a concrete witness against “generated function leave/return proves all mortal allocations reclaimed,” not a use-after-free or leak finding. A return boundary containing a protected escaping alias cannot satisfy the original no-in-flight/all-roots-close premise merely because its own frame left. A call-context summary must state escape and caller continuation, not equate leave with closure.
