The terrain fix returns when the current byte equals the requested block. Proof obligation: no block or derived top/torch membership changes on an unchanged write. For a real transition into TORCH, the prior block differs, so insertion happens once. TORCH-to-other removes the index; other-to-other keeps the existing torch set. Out-of-world writes retain their existing early return. This reasoning assumes the documented World metadata invariant; the fix does not repair arbitrary caller-corrupted metadata. Existing full-world generation changes were dirty before this lane and were preserved.

The renderer originally searched from slot zero for every creation. A separate concrete work red, mesh-work-red/results.json, checks a linear occupied-predicate bound for monotonic creation and even-slot deletion/recreation. The candidate maintains mesh_next_slot: all smaller indices are occupied. Creation scans to the first available slot, makes it occupied, then raises the hint one past it. Deletion lowers the hint to the minimum of it and the freed slot. By induction the next creation chooses the same smallest free handle as the old scan. The seed-335671 bitmap oracle independently searches from zero and checks every slot after every operation; its saved rows each execute 8192 iterations and 8168 actual API operations. Exact zero/negative/future/deleted/double-delete/draw-deleted/update-deleted handles, no-window, malformed vertex size and initial/full-64-slot injected realloc failure controls pass. This hint does not promise constant worst-case create cost for arbitrary deletion patterns. An adversarial delete-first/create-first/create-new sequence can still require a long scan; that is a remaining profiling candidate.
