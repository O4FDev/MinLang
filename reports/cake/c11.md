# c11 — T7/C3: Text views out of shared FrozenBytes (2026-10-31)

READY FOR GATE: 4e6f62078 — additive, measured zero cost on every benchmark (ordinary runtime A/B byte-identical Ir; textindex 0.000%), all area checks green.

**Summary (5 lines)**
1. Added `use "frozen" as frozen`: `frozen.decode(bytes: FrozenBytes, start: Integer, end: Integer): Result<Text, errors.Error>` — one validating pass (identical to `text.decode`), then a **zero-copy Text view** that keeps the frozen buffer alive; slices of it keep sharing.
2. The view is one Text object whose `backing` is the shared handle itself; release drops the handle instead of freeing bytes, so there is no owner Text and no per-call extra allocation.
3. All of it is compiled only into the **thread runtime** (`#if MINYAR_THREADED`), so programs that cannot hold a FrozenBytes compile the exact base runtime: json/textops Ir is byte-identical to the base runtime (0.000%), and textindex is 0.000% at 1 and 4 threads.
4. On a 5 MB corpus the shape `FrozenBytes -> join shard views -> split` is 20 ms vs 50 ms for the old copy-per-branch join (2.5x at 4 threads) and 128.6 M vs 472.0 M Ir per-word-decode (3.7x); per-word views also dropped from 592 M to 450.9 M when the owner Text was removed.
5. No API break and no lost guarantee: FrozenBytes/thread/join APIs and docs are unchanged; the module is imported explicitly; exact ownership runs (O0/O2) and TSan cover it.

## API (before/after)

Before (the only way to read Text out of shared input):
```minyar
let local = copyFrozenBytes(input)                       // whole-buffer Bytes copy
let word = text.decodeOrStop(local.slice(start, end))    // another copy per word
```
After:
```minyar
use "frozen" as frozen
match frozen.decode(input, start, end) {                 // validates, no copy
    Ok(word) { sum += word.length }                      // view keeps input alive
    Err(problem) { return -1 }
}
```
Bounds outside the buffer stop like a Text slice; a range that splits a character is not UTF-8 on its own and is an invalid-data `Err`; validation is `utf8_scan`, the same pass as `text.decode`.

## Design
- `runtime/minyar_thread_buffers.h`: `minyar_runtime_frozenText` validates the range, makes one `new_text` over the frozen payload, sets `backing` to the leaf and retains it.
- `runtime/minyar_runtime.c` / `minyar_text.h` (thread runtime only): `text_backing_shared` recognizes a backing whose RcObject kind is not `RC_TEXT`; slice keeps sharing instead of reading a root length, trim measures the view, split compaction keeps the shared buffer.
- `runtime/minyar_bounded_rc.h` / `minyar_cycle_bounded_rc.h` (thread runtime only): a shared handle that dies with its view is finished inline (one unit) instead of entering the object queue (a handle has no fields for the queue cursor). Ordinary views are untouched.
- `compiler/stages/native.min`: a `native "runtime"` function may take a shared FrozenBytes handle (the opaque leaf) — only for the runtime library. `compiler/thread-compiler.min`: audit entry for `minyar_runtime_frozenText   (9,1,1)`.
- `library/frozen.min`, `docs/language.md` FrozenBytes section, tests in `tests/parallel-join.min` and `tests/thread-programs.min`.

Guarantees checked: exact ownership contract at O0/O2 (`check-parallel-join`, `check-thread-programs`, `check-bounded`, `check-owner-queue-batching`, `check-backlog-pacing`, `check-thread-runtime`, `check-thread-runtime-ir`); TSan (`check-thread-programs-tsan`, two threads reading one frozen buffer); byte-for-byte output equality of every prototype pair; no suite Ir change.
