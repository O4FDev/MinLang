### (a) index write-up (not shipped)
Before (compiles today, `tests/peer-manifest.min:102`): `json.Value { kind: json.OBJECT; text: ""; number: 0.0; truth: false; items: items; keys: keys }`
After: same literal is a compile error once `Value` has a private field (`docs/language.md:1028`), and a lazy index would mutate a tree threads may share.

## Shipped change

`library/json.min`: `numberLeaf` and `asInteger` call a new private `jsonInteger(Text): Integer`
(`NOT_INTEGER` = `-9223372036854775807 - 1` for "not 1–18 signed digits"); `numberLeaf` keeps `-0`
negative zero, `asInteger` falls back to `textTools.integer` for anything else. `runtime/minyar_text.h`
adds `minyar_runtime_jsonInteger` (byte scan, no allocation, never overflows: 18 digits < 2^63).
`compiler/determinism-audit.min` classifies it pure; `compiler/thread-compiler.min` allows it
(`1(2)`, borrowed Text only). `docs/json-numbers.md`: one sentence.
