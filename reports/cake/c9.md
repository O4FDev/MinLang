READY FOR GATE: a711c0ade (+e315dce0b docs)

**Summary (5 lines)**
1. `parallel for` iterations can now create `Text`, records and `List`s of their own: each iteration owns them on the worker's ownership domain, releases them before it ends, and they cannot escape (not into a captured buffer, not through the loop's result, not into a call). `let label = Text(values[index]) + "!"` inside a `parallel for` used to be a compile error; it now runs on the pool.
2. To make that safe the worker of an *owning* loop enters its own ownership frame per chunk (`minyar_rc_enter`/`minyar_rc_leave`), keeps the `minyar_rc_*` calls that were previously stripped, and drains at the chunk boundary (`minyar_parallel_chunk_drain`), so a worker's heap stays bounded; a loop of scalars/borrowed buffers is byte-identical to before.
3. A program with such a loop now selects the per-thread ownership runtime (`; minyar-thread-runtime: 1`) — that turned out to be the missing safety piece: with the ordinary runtime the pool workers shared one global frame/heap and freed each other's objects (ASAN heap-use-after-free, fixed and re-verified clean).
4. Cost: zero on everything that does not own — Ir identical on all 25 serial compare programs and on bothmodes textindex/mapreduce at 1 and 4 threads (3,432.5M / 3,434.2M and 1,853.2M / 1,855.1M, same as base). The feature's demo (400k items, per-item Text+record building) is 165–173 ms at 1 thread (same as the plain `for` version, +2.2% Ir) and 95–102 ms at 4 threads = 1.7x.
5. Status **win (first step of T7)**: race freedom kept (per-domain RC, immutable captures), no API break, docs updated; remaining gaps in the last section.

**Before / after for Luke**

```minyar
// before: rejected — "shared values may only be scalar buffers read by index or through .length"
parallel for index in 0..values.length { widths[index] = (Text(values[index]) + "!").length }
// after: compiles; the Text is built and dropped on the worker that runs the iteration
parallel for index in 0..values.length { let label = Text(values[index]) + "!"; widths[index] = label.length }
```

**Guarantees**
- Race freedom: every participant owns its frame and its values; no count is shared; captures stay read-only (aliasing a captured managed value is still rejected — probe e3).
- Bounded cleanup: a chunk drains its own deferred releases when it ends and nothing escapes to the caller, so no worker heap grows with the loop (`docs/bounded-runtime-contract.md` unchanged).
- Determinism, checked overflow, bounds checks, Unicode indexing, live patching: untouched (no change to existing paths; Ir identical).
- API: no break; programs without owning loops compile to the same IR (`a711c0ade` touches only loops that own).
