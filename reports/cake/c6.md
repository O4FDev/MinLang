## How it works

`rc_system_new_page` hands out the class's static page once the class has already freed a page,
otherwise `malloc`s as before; the page carries `storage = RC_STATIC_PAGE`. When such a page empties,
`rc_system_deallocate` resets it and releases it for the class's next object instead of `free`ing it.
Nothing is retained on the heap (the memory is BSS), so `live_bytes`, the "an allocating program calls
malloc" probe and the small-heap page-recovery assertions all behave exactly as at base.
