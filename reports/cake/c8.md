# c8 — Text scanning loops on one counted-ASCII test (rest of U4)

READY FOR GATE: 821bca9bb

**5-line summary.** Text loop versioning now exists for `while`, `for-in-text` and range `for` loops: one test of every
Text the loop reads (counted and offsets-null = ASCII) enters a copy whose character reads are `bytes[position]` at a
hoisted length and whose `text.length` reads are the hoisted count; every other Text runs the loop unchanged with the
same result and the same traps. exprparse's `skipSpaces` went from ~12 instructions per space to 5 (`cmpq`/`jae`/
`movzbl`/`cmpl`/`jne`) and tokenizer's inner scans the same way. Compare Ir: exprparse -4.00%, tokenizer -5.05%, the
other 20 programs and all six bothmodes programs identical to base; serial and parallel modes unchanged. No API or
documented-behaviour change: `t[i]`, `t.length`, `for c in t` produce the same values, the same out-of-range and
negative traps, and Unicode character indexing still goes through the counted/indexed runtime path.

## What changed

- `compiler/stages/runtime-abi.min`: adds `@.minyar.text.character.known(text, position, length, bytes)` to the Text
  read helpers: `position < length` loads the byte, otherwise it calls `.minyar.text.character`, so a negative or
  out-of-range position traps exactly as before.
- `compiler/stages/loop-versioning.min`: `textLoopVersion` classifies the loop region (reusing `LoopCopy`,
  `loopClassify`, `loopRename`), resolves each `.minyar.text.character` / `.minyar.text.length` operand to a Text that is
  the same header on every iteration, hoists that header's character length, counted flag, offsets pointer and bytes
  buffer once before the loop, and emits a copy of the region that reads bytes directly and names the hoisted length.
  A value defined before the loop is invariant (SSA); a local must be neither stored nor have its address taken
  (`loopLocalEscapes` — a callee could store through it); a reference record field's slot is hoisted only in a call-free
  loop that does not store that same field index (`loopFieldStored`).
- `compiler/stages/statements.min` (while) and `compiler/stages/assignment.min` (for): call it after the existing
  `versionPureWhile`/`versionPureLoop`, so the strip setup is shared by both copies and the guard runs at each strip.
- `compiler/stages/assignment.min` / `compiler/stages/ownership.min`: one output piece can hold a whole loop copy, so
  `settleIdleQueriesIn` settles every query line in a piece and `withoutServiceCalls` drops every service call in it.
  This keeps frame-free functions (no frame, nothing to service) correct and keeps the bounded-cleanup contract
  unchanged elsewhere (a loop with a frame still services at every iteration in both copies).
- `tests/text-scanning.min`: record-field `while` scan, `for c in text`, Unicode text through the same loops, empty
  Text, and a trap inside the fast copy; IR assertions for `.minyar.text.character.known` and the retained counted loop.

## Guarantees checked

- Character indexing semantics: `t[i]` is still the i-th *character*; the fast copy is entered only when the Text is
  counted and has no character offsets, which is exactly the runtime's own ASCII fast path. Unicode Text (offsets or
  uncounted) takes the unchanged loop; tests cover "añ🙂b" in while, for-in and range loops.
- Traps: out-of-range and negative positions fall out of `character.known`'s unsigned compare into the checked helper,
  which traps with the documented message (test asserts both the message and the output before it).
- Bounded cleanup: loops with a frame keep `minyar_rc_step()`/`minyar_rc_idle()` per iteration in both copies; only
  frame-free functions (nothing to service) drop them.
- Determinism, race freedom: no new shared state; the guard reads an immutable header.
- API: unchanged (yes/no = yes, no API change).
