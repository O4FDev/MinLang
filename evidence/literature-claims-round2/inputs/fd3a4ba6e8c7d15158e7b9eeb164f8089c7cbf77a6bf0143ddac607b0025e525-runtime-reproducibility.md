# Runtime evidence reproduction checks

These checks follow actual campaign failures and corrections. They describe the retained harness evidence, not a broad production certification procedure.

- Read the result JSON mode fields and observed coverage before reporting totals. The earlier Text invocation omitted `--language`: 64 C-only checks were incorrectly described as 107 native/generated checks, then corrected. The final explicit language invocation records 107 checks, 21 C configurations,21 generated executions and 21 expected traps. Current language probes record requested mode and actual executions.
- Distinguish sanitized C runtime from generated LLVM. Early generated links lacked ASan definition attributes; current relevant runners apply the matching helper and verify every definition. UBSan on C does not imply generated UBSan. Leak detection is disabled and recorded.
- Pin immutable source versions before running, record compiler artifact/LLVM hashes when present, and keep instrumentation separate from production. An older recorded pre-mutation source hash differed from the final copied bytes in two fixtures; explicit before/after fields reconstruct both. The durable index retains those mismatches rather than rewriting raw results.
- Preserve classifier/setup failures. The first owner-debt calibration also OOMed with the correct guard, so it was an invalid adversary, not a runtime defect. The first same-credit admission run reproduced the expected bounded-heap OOM but expected the generic diagnostic; only the classifier was corrected. New API/soak fixture compile adapter errors remain distinct from executed semantic reds.
- Separate a kernel/private detach replay from public operations and their automatic hooks. Ownership-model trace snapshots required immutable copies; model operation wrappers then included public pre/post hooks. A task count is neither remaining work nor retained bytes.
- Keep compound-operation allowance, actual queued work and immediate destruction separate. Each allocation has its own K hook; moving two existing hooks is not an additional 2K budget and does not prove allocation admission. Countful helpers are not uninstrumented timing binaries.
- Retain all paired measurements and negative controls, including the fixed List growth slowdown and ASCII no-query slowdown. Source snapshots and busy-host conditions belong with the result; host-starved wall timeouts are incomplete evidence.
- Read the durable archive without `build`: it preserves selected raw JSON, exact fixtures/helpers, hashes and reconstructable runtime diffs. Executables, compiler artifacts and LLVM are deliberately excluded; generated reproduction needs a matching or separately validated compiler. New soak results are written directly under the durable research directory, with minute summaries and bounded traces.
- A soak checkpoint's exact requested/object recovery does not imply RSS release. The long fixed cohort uses monotonic elapsed duration, but its absolute monotonic origin was not persisted. Its UTC launch, elapsed summaries and watchdog are available; an estimated absolute origin must be labeled approximate. Future cohorts will persist the origin explicitly.

No full-gate or coverage record is promoted to the final source snapshot when its pinned hashes predate accepted changes. Blocked execution remains blocked scope; a focused profile matrix or completed model corpus has its own bounded conclusion.
